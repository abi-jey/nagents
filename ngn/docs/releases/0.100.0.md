# ngn 0.100.0

The first independent Rust harness/TUI/web-host baseline. Agent Runtime Protocol
v1 separates native tool execution and host control from the optional Python
nagents agent/model loop.

## Start

```sh
./ngn --version
./ngn --demo -C /path/to/project
./ngn --demo -C /path/to/project serve
```

Open the exact printed loopback URL. Install the optional `ngn_nagents` wheel
into a separate Python environment and configure its interpreter/provider to use
a live model. See [README](../../README.md).

## Acceptance checks

Before tagging the local release:

- `cargo fmt --all --check`
- `cargo clippy --workspace --all-targets -- -D warnings`
- `cargo test --workspace`
- Adapter lint, formatting, strict types and tests
- `pre-commit run --all-files`
- Real local fixture `scripts/smoke.py` against the built release binary

Smoke coverage includes CLI/native read, library session resume, headless mutation
denial, HTTP security, WebSocket replay, exact approval binding, approved native
write, idempotency, cancellation, real-PTY interaction and terminal mode restoration.
The fixture does **not** validate paid-provider accounts, microphone/media, all
legacy features, all terminal emulators, or untested operating systems.

### Recorded local acceptance — 2026-11-17

The optimized release binary and the **built adapter wheel** passed the smoke
checks together (not only development source imports):

```text
ngn 0.100.0
PASS: real nagents Agent.run → protocol → native Rust tools → resume; headless approvals fail closed
PASS: HTTP security, authenticated WebSocket events/replay, approval binding, native writes, idempotency and cancellation
PASS: real-PTY Rust TUI, native approval and clean exit
PASS: real-PTY TUI → nagents Agent.run → approved native Rust write; terminal mode restored
```

All nine pre-commit gates passed. Coverage includes **20 Rust tests, 4 Python
adapter tests, and 5 browser-client logic tests**. An additional **20 core-suite
repetitions (220 tests)** passed after fixing an intermittent workspace-lock
reopen race during concurrent shell spawning. The browser logic tests use a DOM
fixture; they are not a claim of cross-browser visual testing.

Stabilization before tagging also fixed stale browser busy-state responses,
duplicate send gestures, expired approval replay, session-picker scrolling,
long-transcript tail visibility, and graceful SIGTERM/terminal restoration.

## Artifacts and publication

Local artifacts go under `releases/v0.100.0/`: Linux x86_64 binary archive,
optional Python adapter wheel, source archive and SHA-256 checksums. The Linux
binary uses the build machine's system C runtime; it is not a universal static
Linux binary. The source and wheel are portable within their documented limits.

No remote is configured in the new repository yet. A local Git tag and artifacts
are not a GitHub/PyPI/crates.io publication; remote publication requires selecting
the repository/registry and its visibility/credentials.

## Known gaps

See [migration status](../migration.md). In particular, Rust-owned subagent
orchestration is the intended design but is **not implemented** in this baseline.
The initial web UI is new and deliberately small; it is not the old React client
ported one-to-one. Existing Python ngn installations remain available independently.
