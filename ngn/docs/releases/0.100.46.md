# v0.100.46

Restore the React workspace in native ngn, add a terminal transcript scrollbar, and plan the migration to one Python engine.

- `ngn serve` embeds the shared React workspace: resizable Sessions and Team
  panels, conversation Markdown and tool cards, one-time approvals, and desktop
  and touch composer controls. Node.js is required to build from source, not to
  use an installed binary.
- In the TUI, click the transcript scrollbar track or drag its thumb to browse
  history. Return to the bottom to follow new output.
- The [migration plan](../migration.md) and [route and TUI inventory](../engine-inventory.md)
  follow ADR 0001. This release does not switch the engine, change the runtime
  protocol, or migrate the state database.
