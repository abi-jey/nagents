# v0.100.21

Fix #311: name the occupied ngn destination, distinguish permission errors, and show a version-pinned side-by-side retry using a separate bin directory and prefix without replacing the existing ngn.

The retry uses the release that emitted the error, even if GitHub marks a
different release as Latest. The matching release assets must be available
for the download. Run the new installation by the full path printed in the
retry instructions; no change to `PATH` is required.
