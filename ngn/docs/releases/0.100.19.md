# v0.100.19

The native POSIX TUI shows a brief normal-screen startup prelude before opening the workspace. Enter or Space skips it; Escape, Ctrl+C, or Ctrl+Q exits. Printable input can carry into the draft without sending, and reduced motion skips the prelude.

**Known limitation (follow-up):** If session setup is unusually slow, the native TUI restores the terminal at the end of the prelude but waits for setup before opening the workspace. Keys typed in that interval may echo on the normal screen and are not part of the prelude's draft handoff. The Python TUI can mount the workspace while setup is still pending.
