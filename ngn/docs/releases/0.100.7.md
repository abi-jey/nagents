# v0.100.7

Native Python configuration safeguards, local diagnostics, terminal parity improvements, and read-only Python history archives.

- **Python configuration and auth:** Without `--config`, native ngn reads existing
  Python provider/model settings and honors `read_only`, without writing config
  or importing Python approval or tool policies. Python ChatGPT credentials stay
  separate: if the selected route would use them, configure native ChatGPT and
  sign in to the intended account rather than falling back to another route.
  `auth: "codex"` requires local Codex files (`$CODEX_HOME` or `~/.codex`) and
  honors their OAuth or API-key policy. The welcome screen and `ngn doctor`
  explain unavailable connections; `doctor` also lists legacy files read.
  Legacy Foundry/Azure `api_version` routes, Entra auth, and the `assistant.md`
  system prompt are not imported.
- **Logs:** Local lifecycle diagnostics omit prompts, tool payloads, credentials
  and runner stderr; the TUI shows the log path on exit when available. Provider
  HTTP capture is off by default. Use `--wire-log` to enable it or `--no-wire-log`
  to override an environment default. The private wire log redacts transport
  authentication, but payloads can still contain sensitive content.
- **Terminal parity:** The Textual-style footer shows activity and the selected
  provider/model. The filter-first session picker (`F2`, `/sessions`, or bare
  `/resume`) searches by title or ID. Tool calls update a single transcript row
  through their lifecycle. Typing `/` offers native command suggestions; Tab or
  Enter fills a suggestion without executing it.
- **Python history:** On Linux and macOS, normal workspace startup can make a
  one-time copy of supported Python user/assistant text into separate Rust-owned
  read-only archives (host schema 5). The original database is not changed.
  Archives are not synced or resumable; no model context, credentials, approvals,
  or tool state are imported and no actions are replayed. Missing, busy, unsafe,
  unsupported, or WAL databases are skipped without blocking startup. If needed,
  close Python ngn and retry, or make a standalone rollback-journal backup and
  run `ngn -C WORKSPACE upgrade --from BACKUP --data-dir FRESH_DIR`.
  Back up native state before upgrading; use separate state or restore a backup
  to downgrade. See [Python session history](../../README.md#python-session-history)
  for discovery paths and source limits.
