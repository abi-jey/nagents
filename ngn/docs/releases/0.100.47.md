# v0.100.47

Opt-in Python engine, Enter-to-steer in the browser, and elapsed/timeout columns in TUI tool headers.

- **Opt-in Python engine (development).** `ngn --engine=python` connects the
  TUI and `ngn serve` to the headless `nagents engine` from
  [ADR 0001](../../../docs/adr/0001-python-core-rust-tui.md) through the
  versioned `/api/v1` contract. The Rust host stays the default. See
  [runtime status](../../../docs/adr/0001-runtime-status.md) for what the
  engine supports, including optional ABI3 discovery and diff helpers and a
  read-only import of Rust host history.
- **Browser steering keys.** While a turn runs, Enter (or **Steer**) steers it
  and Ctrl+Enter (⌘+Enter on macOS) queues the message for after the current
  work, as in the TUI. Touch keeps Return as a newline and shows **Steer** and
  **Queue**. The separate **Steer active turn** button is gone.
- **TUI tool header columns.** Tool headers again show right-aligned outcome,
  elapsed and `/ timeout` columns, as in the Python TUI, so times line up from
  row to row. A call's own `timeout`, `timeout_seconds` or `timeout_ms`
  argument is shown; shell calls show the configured shell timeout. Narrow
  terminals fall back to the compact header.
- Child agent rows keep long session IDs from covering the state badge.

This release does not change the default engine, the runtime protocol or the
state database.
