# v0.100.47

One Python engine behind the Rust TUI and browser: the Rust host is removed, old history is imported once, Enter steers in the browser, and TUI tool headers show elapsed/timeout columns.

- **One engine.** ngn is now a client of the Python `nagents engine` only. The
  in-process Rust host (`ngn-core`), its protocol crate, the per-run
  `ngn_nagents` adapter and every engine choice are removed. The TUI,
  `run --json` and `ngn serve` start or attach to the workspace's engine over
  the versioned `/api/v1` contract ([ADR 0001](../../../docs/adr/0001-python-core-rust-tui.md)).
  `--standalone` runs a private engine; `--engine-demo` runs offline.
- **Bundle.** The self-contained bundle now pins `nagents[engine]` (FastAPI,
  Uvicorn, Pydantic, websockets) in its CPython for Linux x86_64 and macOS.
  `ngn-nagents` remains only as a compatibility marker so `ngn update` from
  0.100.46 and earlier keeps working.
- **Earlier history.** The first time the engine starts in a workspace, it
  copies that workspace's Rust host history (`~/.local/share/ngn-rust/...`)
  into read-only sessions through a private backup, once, without changing the
  old file. `nagents import-host` imports a backup from elsewhere.
- **Commands.** `ngn auth login|status|logout` and `ngn doctor` run the
  engine's own commands in the engine's Python; `doctor` first prints which
  Python that is. `ngn upgrade` and `--engine` are gone.
- **Browser steering keys.** While a turn runs, Enter (or **Steer**) steers it
  and Ctrl+Enter (⌘+Enter on macOS) queues the message for after the current
  work, as in the TUI. Touch keeps Return as a newline and shows **Steer** and
  **Queue**. The separate **Steer active turn** button is gone.
- **TUI tool header columns.** Tool headers again show right-aligned outcome,
  elapsed and `/ timeout` columns, as in the Python TUI, so times line up from
  row to row. A call's own `timeout`, `timeout_seconds` or `timeout_ms`
  argument is shown; shell calls show the configured shell timeout. Narrow
  terminals fall back to the compact header.
- Child agent rows keep long session IDs from covering the state badge.
- Saved painted composer themes (`graphite`, `ocean`, `ember`) no longer tint
  the native composer; user rows still follow the terminal background.

**Before updating**, stop running ngn clients. Keep `~/.local/share/ngn-rust`
if you want to keep the original Rust host files; the engine only reads them.
