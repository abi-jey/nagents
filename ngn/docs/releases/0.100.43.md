# v0.100.43

Remove the Python terminal UI; the native ngn is the interactive terminal client. The Python ngn keeps run, serve, sessions, a2a, login, logout and doctor, and the tui extra and Textual dependency are gone. Docs explain how ngn and nagents are pronounced.

## Upgrading from the Python terminal UI

- Install the native client for an interactive terminal:
  `curl -fsSL https://github.com/abi-jey/nagents/releases/latest/download/install.sh | sh`
- The Python `ngn` without a subcommand now prints this pointer and exits with code 2.
  Use `ngn run` for headless prompts and `ngn serve` for the browser client.
- `ngn resume` and the `--theme`, `--theme-background`, `--no-animations` and
  `--tui-performance` flags are removed. The matching config fields still load, and
  the native ngn still reads saved theme settings.
- `pip install 'nagents[tui]'` no longer installs anything extra; drop the `tui`
  extra from install commands.
